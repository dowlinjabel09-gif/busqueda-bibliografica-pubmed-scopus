# Búsqueda bibliográfica en PubMed y Scopus
Descripción: 

Este repositorio tiene como objetivo organizar el proceso de búsqueda de información científica en las bases de datos PubMed y Scopus.

Contenido:
- Pregunta de investigación PICO/PECO.
- Identificación de descriptores MeSH y DeCS.
- Fórmulas de búsqueda para PubMed y Scopus.
- Artículos científicos seleccionados.
- Organización del trabajo por semanas.

Objetivo:

Desarrollar estrategias de búsqueda bibliográfica que permitan identificar artículos científicos relevantes para responder a la pregunta de investigación.
